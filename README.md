# 🧪 Data Collection and Pre-Processing Lab Assignment

## 📌 Project Synopsis  
This project walks through a 12-step Data Engineering pipeline using a realistic e-commerce dataset. It covers ingestion, cleaning, transformation, and feature engineering, culminating in analytical insights and a merged data dictionary. The goal is to demonstrate mastery of Python structures, class design, and serialization formats while enriching raw data with synthetic metadata.

## 🚀 Quick Start  
```bash
python -m venv venv  
pip install -r requirements.txt  
jupyter notebook
```

## 📂 Data Sources  
- **Primary CSV**: [1000 Sales Records – ExcelBIAnalytics](https://excelbianalytics.com/wp/downloads-18-sample-csv-files-data-sets-for-testing-sales/)  
- **Secondary Metadata**: Any open dataset (e.g., product catalogues, city lookups, coupon descriptions) or create synthetic dataset from Faker 

Save both files in a folder named `data/` inside your repository.

## 📘 Notebook Structure  
The notebook follows 12  steps:
1. Load and preview raw data  
2. Justify Python containers (dict vs namedtuple vs set)  
3. Implement reusable functions and classes  
4. Map data structures  
5. Profile key metrics  
6. Identify dirty data  
7. Apply cleaning rules  
8. Transform fields  
9. Engineer new features  
10. Aggregate insights  
11. Serialize to JSON  
12. Reflect on function design  

Includes a final **Data Dictionary** - {../data/cleaned_data.json} merging both sources.
